# Lienzo UI 1.2.3

## Español
- **Interfaz en inglés completa**: la barra de estado y varios textos del inspector seguían en español; ahora se traducen.
- **Servidor MCP**: un elemento llamado «3» ya no pierde ante el elemento de id 3 (gana el nombre exacto).
- **Servidor MCP**: límites de tamaño en nombres, textos y listas, para que una orden descontrolada no deje la app minutos sin responder.
- Se actualiza desde la propia app (botón **Actualizar a 1.2.3**).

## English
- **Fully English interface**: the status bar and several inspector texts were still in Spanish; they are now translated.
- **MCP server**: an element named "3" no longer loses to the element with id 3 (the exact name wins).
- **MCP server**: size limits on names, texts and lists, so a runaway command can't leave the app unresponsive for minutes.
- Update from inside the app (**Update to 1.2.3** button).
