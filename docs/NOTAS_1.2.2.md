# Lienzo UI 1.2.2

## Español
- Un diseño con padres en ciclo ya no cuelga la app al seleccionar, borrar o duplicar.
- Exportar un diseño con ancho o alto negativos ya no cierra la app.
- Los ids repetidos y un `next_id` demasiado bajo se corrigen al abrir el archivo.
- Los títulos muy largos se acortan en los nombres de archivo exportados.
- Se actualiza desde la propia app (botón **Actualizar a 1.2.2**) y **Reiniciar ahora** abre la versión nueva.

## English
- A design with parents in a cycle no longer freezes the app when you select, delete or duplicate.
- Exporting a design with negative widths or heights no longer closes the app.
- Duplicate ids and a too-low `next_id` are fixed when the file is opened.
- Very long titles are shortened in exported file names.
- Update from inside the app (**Update to 1.2.2** button); **Restart now** opens the new version.
