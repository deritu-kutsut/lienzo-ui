# Обучение для новичков

🌐 [English](TUTORIAL_BEGINNERS.md) · [Español](TUTORIAL_BEGINNERS.es.md) · [Português](TUTORIAL_BEGINNERS.pt.md) · [Français](TUTORIAL_BEGINNERS.fr.md) · [Deutsch](TUTORIAL_BEGINNERS.de.md) · [Italiano](TUTORIAL_BEGINNERS.it.md) · [Русский](TUTORIAL_BEGINNERS.ru.md) · [简体中文](TUTORIAL_BEGINNERS.zh.md) · [日本語](TUTORIAL_BEGINNERS.ja.md) · [한국어](TUTORIAL_BEGINNERS.ko.md)

Ваш первый интерфейс в Lienzo UI и первый экспорт в Unity. Программирование не нужно.

## 1. Установка и запуск

1. Скачайте `LienzoUI-windows.zip` со страницы релизов на GitHub или с itch.io.
2. Распакуйте архив и откройте `lienzo-ui.exe`.
3. При первом запуске открывается **обучение** (этот же текст внутри приложения). Когда вы его закончите или нажмёте «Пропустить и перейти в редактор», откроется редактор. Чтобы увидеть обучение снова: кнопка **Обучение** в верхней панели или **F1**.

Чтобы переключить приложение на русский: кнопка **Доступность** › **Язык** › Русский.

![Обучение внутри приложения](images/tutorial.png)

## 2. Экран

| Область | Что там есть |
|---|---|
| Верхняя панель | Файл, Изменить, Вид, Canvas, **Тест**, имя макета, **Доступность**, **Проверить**, **Темы**, **Обучение**, **Сохранить**, **Код…**, **Экспорт в Unity** |
| Левая панель | **Иерархия** (слои), **Элементы**, **Шаблоны**, **Текст**, **Изображения**, **Плагины**, **Сообщество** |
| Центр | Холст: экран вашей игры (по умолчанию 1920 × 1080) |
| Справа | **Инспектор**: свойства выделенного элемента |

![Редактор](images/editor.png)

## 3. Начните с шаблона

В **Шаблоны** выберите один из 15 макетов: Главное меню, Игровой HUD, Окно диалога, Настройки, Инвентарь, Меню паузы, Конец игры, Выбор уровня, Экран загрузки, Диалог персонажа, Таблица лидеров или Выбор персонажа. В нём можно изменить всё, а Ctrl+Z отменяет изменение. Чтобы начать с нуля: «Пустой». Два из них выполнены в стиле пиксель-арт: «HUD пиксельной RPG» и «Главное меню в пикселях».

## 4. Редактирование

- Перетаскивайте элементы из **Элементы** на холст. В **Готовые компоненты** есть кнопки, полосы здоровья и маны, карточки, значки и слоты инвентаря.
- В **Текст** есть стили заголовков и части HUD: очки, таймер, монеты, числа урона, комбо, метка уровня и субтитры.
- Щелчок выделяет; перетаскивание перемещает; углы меняют размер; верхний маркер поворачивает.
- Двойной щелчок по тексту открывает его для ввода.
- В **Инспектор** меняйте цвета, границы, тени, шрифты и якоря.

| Горячая клавиша | Действие |
|---|---|
| Ctrl+Z / Ctrl+Y | Отменить / повторить |
| Ctrl+D / Del | Дублировать / удалить |
| Ctrl+G / Ctrl+Shift+G | Сгруппировать / разгруппировать |
| Стрелки (Shift) | Сдвиг на 1 px (10 px) |
| Ctrl+S | Сохранить |
| F5 | Тест |
| Ctrl+E | Экспорт в Unity |
| F1 | Обучение |

## 5. Тест

Нажмите **Тест** (F5): интерфейс становится интерактивным, и можно выбрать другие экраны (телефон, 4:3, сверхширокий), чтобы посмотреть, как он адаптируется. Esc выходит из режима проверки, и макет возвращается к состоянию до проверки.

## 6. Проверка

Нажмите **Проверить** в верхней панели. Приложение предупредит о слишком мелком тексте, низком контрасте, слишком маленьких для касания кнопках, элементах за пределами страницы, повторяющихся именах и отсутствующих изображениях. Щёлкните по предупреждению, чтобы выделить этот элемент и исправить его.

## 7. Экспорт в Unity

1. Нажмите **Экспорт в Unity** (Ctrl+E). В первый раз выберите папку вашего проекта (ту, что содержит `Assets`).
2. Вернитесь в Unity: макет появится как prefab в `Assets/EditorGUI/Prefabs`.
3. Перетащите его в сцену или воспользуйтесь меню **Tools › Lienzo UI › Import design into scene…**.

При каждом новом экспорте Unity обновляет prefab сам.

## Встроенные изображения

Вкладка «Изображения» на левой панели содержит готовую графику, файлы не нужны:

- Фишки сверху фильтруют по категориям: «Ваши изображения», «Фоны», «Рамки», «Кнопки», «Иконки», Pixel art и «Градиенты». Поиск находит по названию или тегу.
- Щёлкните по элементу, чтобы добавить его, или перетащите на холст. Рамки и кнопки идут с готовой границей 9-slice, поэтому растягиваются без искажения углов. Фоны ставятся позади всего остального.
- При первом использовании картинка копируется в вашу библиотеку и экспортируется в Unity вместе с макетом.
- Для пиксельных спрайтов включите Pixel art в Инспекторе холста (при пустом выделении), чтобы они оставались чёткими.

## Вертикальные экраны

Телефоны часто держат вертикально. Для этого Lienzo UI хранит второй макет, не трогая первый:

- Переключайте вид кнопками «Пейзаж» / «Портрет» на верхней панели.
- При пустом выделении откройте в Инспекторе «Вертикальный макет» и нажмите «Создать вертикальный макет». Элементы стартуют там, где они стоят в горизонтальном макете.
- В вертикальном виде всё, что вы двигаете или масштабируете, меняет только вертикальный макет. Правый клик по элементу › «Вернуть к горизонтальному» отменяет одно изменение.
- Экспорт содержит оба макета: в Unity префаб сам переключается на вертикальный, когда экран выше, чем шире.

Каждый шаблон уже содержит собственный вертикальный макет: примените шаблон и нажмите «Портрет», чтобы увидеть его в виде для телефонов (1080 × 1920).

## Импорт из Unity

Уже есть интерфейс в Unity? Принесите его в Lienzo UI:

- Файл › Импорт из Unity…
- Выберите префаб uGUI (.prefab) или макет, ранее экспортированный из Lienzo UI (Assets/EditorGUI/Designs/….json).
- Он откроется как новый несохранённый макет: сохраните его как проект, чтобы не потерять.
- Если что-то не удалось преобразовать точно, окно покажет список предупреждений: ничего не теряется молча.
- Если папка вашего проекта Unity найдена, изображения макета подхватываются автоматически.

## Не потеряйте свою работу

- Автосохранение: примерно раз в минуту Lienzo UI сохраняет резервную копию. Отключить можно в «Доступность › Автосохранение».
- Если приложение неожиданно закрылось, при следующем запуске оно спросит «Восстановить несохранённую работу…?». Нажмите «Восстановить», чтобы вернуть её, или «Отбросить», чтобы удалить. Восстановленная работа ещё не является сохранённым файлом: нажмите Ctrl+S, чтобы сохранить.
- Ctrl+S по-прежнему сохраняет проект как обычно.
- Отмена (Ctrl+Z) помнит до 200 шагов (и есть лимит памяти). Если самые старые шаги удаляются, в строке состояния появляется «История сокращена».

## Сообщество

Вкладка «Сообщество» на левой панели — общий каталог плагинов, изображений, шрифтов, шаблонов, элементов и тем:

- Просматривать и устанавливать можно без аккаунта: найдите и нажмите «Установить».
- Чтобы загружать, жаловаться или ставить сердечки, войдите через GitHub или Google и выберите публичное имя. Паролей нет: приложение хранит только это имя.
- При создании профиля вы принимаете правила: никакого вредоносного ПО, ненависти, плагиата и неотмеченного контента 18+. Полный текст — в docs/TERMS.md и docs/COMMUNITY_GUIDELINES.md.
- Контент 18+ скрыт, пока вы не войдёте и не включите «Показывать контент 18+».
- Всё, чем делятся, проверяется до публикации, а на нарушения можно пожаловаться.

Для шрифтов и плагинов нажмите «Предпросмотр», чтобы увидеть пример текста или прочитать, что делает плагин и каков его код, до установки; ничего не устанавливается. Нажмите «Перевести», чтобы прочитать любое описание на своём языке. Используется бесплатный онлайн-сервис, только когда вы нажимаете кнопку, а «Показать оригинал» возвращает исходный текст.
