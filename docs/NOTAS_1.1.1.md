# Lienzo UI 1.1.1

## Español
- **Moderación automática**: todo lo que se sube (también fotos de perfil y banners) se comprueba solo; lo limpio se publica y lo dudoso queda pendiente para una persona.
- La ventana se abre **maximizada**.
- **Paquete gratuito para Unity** (importador, ventana de acceso y 7 ejemplos), enviado a la Asset Store.

## English
- **Automatic moderation**: every upload (profile pictures and banners too) is checked automatically; clean items publish and doubtful ones wait for a person.
- The window now opens **maximized**.
- **Free Unity package** (importer, launcher window and 7 samples), submitted to the Asset Store.
