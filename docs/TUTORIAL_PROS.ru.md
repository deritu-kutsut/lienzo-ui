## Что создаёт экспорт

Всё записывается в `Assets/EditorGUI` проекта Unity:

| Файл | Назначение |
|---|---|
| `Designs/<Design>.json` | Макет. Импортёр пересобирает prefab каждый раз, когда он меняется. |
| `Editor/EditorGuiImporter.cs` | Собирает prefab с помощью uGUI + TextMeshPro. Меню **Tools › Lienzo UI**. |
| `Prefabs/<Design>.prefab` | Готов к использованию. |
| `UI Toolkit/<Design>.uxml` + `.uss` | Версия для UI Toolkit (UIDocument, PanelSettings 1920×1080 Scale With Screen Size). |
| `Scripts/<Design>OnGUI.cs` | Версия для IMGUI: добавьте его на GameObject. |
| `Scripts/<Design>ViewBase.cs` | Типизированные ссылки и события (генерируется заново). |
| `Scripts/<Design>View.cs` | **Ваша** логика: создаётся один раз и никогда не перезаписывается. |
| `Sprites/`, `Fonts/` | Изображения и шрифты, которые использует макет. |

`<Design>` — это название в PascalCase без диакритики (`Menú principal` → `MenuPrincipal`).

Если какого-то изображения нет, ничего не записывается: экспорт останавливается до изменения проекта и сообщает, какой файл не удалось прочитать.

## Якоря и масштабирование

- Когда ничего не выделено, Инспектор показывает **Canvas Scaler**: опорное разрешение, *match* и фон.
- У каждого элемента есть якоря, пивот и смещения, как у `RectTransform`. Когда опорное разрешение меняется, элементы следуют своим якорям.
- Встроенные шаблоны рассчитаны на 1920×1080; на меньших или вертикальных страницах они равномерно уменьшаются, чтобы уместиться.
- Перед экспортом проверьте макет в режиме **Тест** (F5) на нескольких экранах.

## Компоновки и списки

Контейнер может располагать дочерние элементы по горизонтали, по вертикали или сеткой (как *Layout Groups* в Unity), с промежутками и отступами. ScrollView вычисляет своё содержимое. Порядок в Иерархии — это порядок отрисовки.

## Логика

- **В редакторе**: в режиме проверки каждый элемент может по нажатию выполнять скрипт Rhai (`mostrar("Nombre")`, `ocultar`, `alternar`, `texto`, `color`, `mover`…). Полезно для прототипирования переходов. Изменения, сделанные во время проверки, отбрасываются при выходе из режима проверки и никогда не сохраняются и не экспортируются.
- **В Unity**: `<Design>View` наследуется от `<Design>ViewBase`, с одним полем на каждую кнопку, слайдер, переключатель или поле ввода и методами `On<Element>Click` / `On<Element>Changed` для переопределения.

```csharp
public class AjustesView : AjustesViewBase
{
    protected override void OnBotonVolverClick() => gameObject.SetActive(false);
}
```

Давайте интерактивным элементам уникальные имена: скрипты и `GameObject.Find` находят только первое совпадение. **Проверить** предупреждает о повторяющихся именах.

## Проверить макет

Кнопка **Проверить** (и `--revisar` в командной строке) проверяет при опорном разрешении:

| Проверка | Правило |
|---|---|
| Размер текста | Не меньше 18 px при 1080p |
| Контраст | WCAG: 4.5:1 или 3:1 для крупного текста (24 px или 18.7 px полужирным); отключённые элементы управления исключены |
| Размер для касания | Кнопки, переключатели, поля ввода и раскрывающиеся списки — не меньше 64 px по короткой стороне при 1080p |
| Страница | Элементы полностью или частично за пределами страницы |
| Имена | Повторяющиеся имена у интерактивных элементов |
| Изображения | Файлы изображений, которых больше нет |

Контраст ниже 2:1, элементы полностью за пределами страницы и отсутствующие изображения — ошибки; остальное — предупреждения.

## Командная строка

```bash
lienzo-ui --plantillas                                   # выводит список шаблонов (0-12)
lienzo-ui --plantilla 4 --guardar inventario.editorgui.json
lienzo-ui --abrir inventario.editorgui.json --revisar    # код выхода 1, если есть ошибки
lienzo-ui --abrir inventario.editorgui.json --exportar "C:/MyGame"   # без окна
lienzo-ui --abrir inventario.editorgui.json --screenshot capture.png
lienzo-ui --probar 1080x2400                             # открывает в режиме проверки с этим экраном
lienzo-ui --tutorial [--profesional]                     # принудительно открывает обучение
lienzo-ui --sin-tutorial                                 # не открывает его
```

`--guardar`, `--exportar` и `--revisar` не открывают окно: используйте их в скриптах, CI и с [MCP-сервером](MCP.md) (инструмент `revisar_diseno`).

## Исходный код

Rust + [egui](https://github.com/emilk/egui):

| Файл | Содержимое |
|---|---|
| `src/model.rs` | Данные: `Doc`, `Element`, `Kind`, якоря, компоновки, шаблоны |
| `src/canvas.rs` | Холст: выделение, маркеры, направляющие, масштаб |
| `src/panels.rs` | Верхняя панель, боковая панель, Инспектор, окна |
| `src/app.rs` | Состояние, отмена, команды, горячие клавиши |
| `src/render.rs` | Отрисовка элементов и шрифтов |
| `src/revision.rs` | Проверки «Проверить макет» |
| `src/export/` | Экспортёры: `ugui.rs`, `uitk.rs`, `imgui.rs`, `view.rs` и импортёр для Unity |
| `src/tutorial.rs` | Встроенное обучение (страницы на испанском и английском) |
| `src/script.rs` | Скрипты Rhai для режима проверки |

Как расширить: [EXTENDER.md](EXTENDER.md).
