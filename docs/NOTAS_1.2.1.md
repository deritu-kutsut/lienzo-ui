# Lienzo UI 1.2.1

## Español
- **Actualizador corregido**: tras actualizar, «Reiniciar ahora» relanzaba la versión anterior; ahora abre la nueva.
- Las notas de la versión se ven como texto plano en la ventana de actualización.
- Si tienes la 1.2.0, esta versión se instala desde la propia app (botón **Actualizar a 1.2.1**); al terminar, cierra y abre Lienzo UI a mano una vez.

## English
- **Updater fixed**: after updating, "Restart now" relaunched the old version; it now opens the new one.
- Release notes show as plain text in the update window.
- If you're on 1.2.0, update from inside the app (**Update to 1.2.1** button); when it finishes, close and reopen Lienzo UI by hand once.
