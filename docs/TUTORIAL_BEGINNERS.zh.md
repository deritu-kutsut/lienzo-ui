# 新手教程

🌐 [English](TUTORIAL_BEGINNERS.md) · [Español](TUTORIAL_BEGINNERS.es.md) · [Português](TUTORIAL_BEGINNERS.pt.md) · [Français](TUTORIAL_BEGINNERS.fr.md) · [Deutsch](TUTORIAL_BEGINNERS.de.md) · [Italiano](TUTORIAL_BEGINNERS.it.md) · [Русский](TUTORIAL_BEGINNERS.ru.md) · [简体中文](TUTORIAL_BEGINNERS.zh.md) · [日本語](TUTORIAL_BEGINNERS.ja.md) · [한국어](TUTORIAL_BEGINNERS.ko.md)

用 Lienzo UI 制作你的第一个界面，并第一次导出到 Unity。无需编程。

## 1. 安装并打开

1. 从 GitHub 的 Releases 页面或 itch.io 下载 `LienzoUI-windows.zip`。
2. 解压后打开 `lienzo-ui.exe`。
3. 第一次打开时会显示**教程**（就是现在这段内容，位于应用内）。看完教程，或者点击「跳过并前往编辑器」后，编辑器就会打开。想再看一次教程：点击顶栏的**教程**按钮，或按 **F1**。

想把应用切换成中文：点击**无障碍**按钮 › **语言** › 中文。

![应用内的教程](images/tutorial.png)

## 2. 界面

| 区域 | 里面有什么 |
|---|---|
| 顶栏 | 文件、编辑、视图、Canvas、**测试**、设计名称、**无障碍**、**检查**、**主题**、**教程**、**保存**、**代码…**、**导出到 Unity** |
| 左侧栏 | **层级**（图层）、**元素**、**模板**、**文字**、**图片**、**插件**、**社区** |
| 中间 | 画布：你的游戏界面（默认为 1920 × 1080） |
| 右侧 | **Inspector**：所选元素的属性 |

![编辑器](images/editor.png)

## 3. 从模板开始

在**模板**里挑一个布局，共 15 种：主菜单、游戏 HUD、对话框窗口、设置、背包、暂停菜单、游戏结束、关卡选择、加载界面、角色对话、排行榜或角色选择。模板里的所有内容都能修改，按 Ctrl+Z 可撤销修改。想从零开始：选「空白」。其中两个是像素风格：像素风RPG界面和像素风主菜单。

## 4. 编辑

- 把元素从**元素**拖到画布上。**现成组件**里有按钮、生命条和法力条、卡片、徽章和背包格子。
- **文字**里有标题样式和 HUD 部件：得分、计时器、金币、伤害数字、连击、等级标签和字幕。
- 单击选中；拖动移动；拖角调整大小；顶部的手柄用来旋转。
- 双击文字即可输入。
- 在 **Inspector** 中修改颜色、边框、阴影、字体和锚点。

| 快捷键 | 操作 |
|---|---|
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+D / Del | 复制 / 删除 |
| Ctrl+G / Ctrl+Shift+G | 编组 / 取消编组 |
| 方向键（Shift） | 移动 1 px（10 px） |
| Ctrl+S | 保存 |
| F5 | 测试 |
| Ctrl+E | 导出到 Unity |
| F1 | 教程 |

## 5. 测试

点击**测试**（F5）：界面变成可交互的，你还可以切换到其他屏幕（手机、4:3、超宽屏）看它如何自适应。按 Esc 退出测试模式，设计会恢复到测试前的状态。

## 6. 检查

点击顶栏的**检查**。它会提醒文字太小看不清、对比度太低、按钮太小不好点击、元素超出页面、名称重复以及图片缺失。点击某条提示即可选中对应元素并修改它。

## 7. 导出到 Unity

1. 点击**导出到 Unity**（Ctrl+E）。第一次导出时，选择你的项目文件夹（包含 `Assets` 的那个）。
2. 回到 Unity：设计会以 prefab 的形式出现在 `Assets/EditorGUI/Prefabs` 中。
3. 把它拖进场景，或者使用菜单 **Tools › Lienzo UI › Import design into scene…**。

以后每次重新导出，Unity 都会自动更新这个 prefab。

## 内置图片

左侧栏的「图片」标签页自带现成素材，不需要自己准备文件：

- 顶部的筛选标签有：你的图片、背景、边框、按钮、图标、像素艺术和渐变。搜索框可按名称或标签查找。
- 点击某一项即可添加，也可以把它拖到画布上。边框和按钮自带 9-slice 边界，拉伸时四个角不会变形。背景会放在所有内容的最底层。
- 图片在第一次使用时会复制到你的素材库，并随设计一起导出到 Unity。
- 使用像素艺术素材时，请在画布检查器中（不选中任何元素）勾选「像素艺术」，让它们保持清晰。

## 竖屏

手机经常竖着拿。Lienzo UI 为此另存一套布局，不会改动原来的那套：

- 用顶部栏的「风景」/「头像」按钮切换视图（即横屏/竖屏）。
- 不选中任何元素，在检查器中打开「竖屏布局」，点击「创建竖屏布局」。元素一开始位于它们在横屏中的位置。
- 在竖屏视图中，你移动或缩放的内容只会改变竖屏布局。右键点击元素 ›「恢复为横屏」可撤销某一处修改。
- 导出时会包含两套布局：当屏幕高度大于宽度时，Unity 中的 prefab 会自动切换到竖屏布局。

每个模板都自带竖屏布局：应用一个模板，再点击「头像」按钮（即竖屏），就能看到为手机设计的版面（1080 × 1920）。

## 从 Unity 导入

Unity 里已经有界面了？把它带进 Lienzo UI：

- 文件 ›「从 Unity 导入…」
- 选择一个 uGUI prefab（.prefab），或之前由 Lienzo UI 导出的设计（Assets/EditorGUI/Designs/….json）。
- 它会作为新的、未保存的设计打开：请保存为项目以便保留。
- 如果有内容无法精确转换，会弹出窗口列出警告，不会悄悄丢失任何东西。
- 如果找到了你的 Unity 项目文件夹，设计中的图片会被自动找到。

## 别丢了你的工作

- 自动保存：Lienzo UI 大约每分钟保存一份恢复副本。可以在「无障碍 › 自动保存」中关闭。
- 如果应用意外关闭，下次启动时会询问「恢复未保存的工作…？」。点「恢复」找回，点「丢弃」放弃。恢复回来的内容还不是已保存的文件：请按 Ctrl+S 保存。
- Ctrl+S 仍然像往常一样保存你的项目。
- 撤销（Ctrl+Z）最多记住 200 步（另有内存上限）。如果最早的步骤被丢弃，状态栏会显示「历史记录已精简」。

## 社区

左侧栏的「社区」标签页是一个共享目录，收录插件、图片、字体、模板、元素和主题：

- 浏览和安装不需要账号：搜索后点击「安装」即可。
- 要上传、举报或点赞，需要用 GitHub 或 Google 登录并选择一个公开名称。没有密码：应用只保存这个名称。
- 创建个人资料时你需要接受规则：禁止恶意软件、仇恨内容、抄袭，以及未标注的 18+ 内容。完整内容见 docs/TERMS.md 和 docs/COMMUNITY_GUIDELINES.md。
- 18+ 内容默认隐藏，登录并开启「显示 18+ 内容」后才会显示。
- 所有共享内容在发布前都会经过审核，你也可以举报违反规则的内容。

对于字体和插件，安装前点击「预览」可以看到示例文字，或查看插件的功能和代码；不会安装任何内容。点击「翻译」可以用你的语言阅读任何描述。它只在你点击时使用免费的在线服务，点击「显示原文」可返回原文。
