# Lienzo UI 1.3.2

## Español
- **Chino simplificado, japonés y coreano** en la interfaz, el tutorial integrado y los tutoriales de `docs/`: Lienzo UI ya está en 10 idiomas. Cámbialo en **Accesibilidad › Idioma**.
- Se usan las fuentes que ya trae el sistema (Microsoft YaHei, Yu Gothic, Malgun Gothic en Windows) y solo se cargan al elegir uno de estos idiomas; si falta, Accesibilidad lo avisa.
- Tutoriales escritos (novatos y profesionales) en los 10 idiomas, con una línea para cambiar de idioma.

## English
- **Simplified Chinese, Japanese and Korean** for the interface, the built-in tutorial and the written tutorials: Lienzo UI now speaks 10 languages. Switch in **Accessibility › Language**.
- It uses the fonts your system already has (Microsoft YaHei, Yu Gothic, Malgun Gothic on Windows), loaded only when you pick one of these languages; if one is missing, Accessibility tells you.
- Written tutorials (beginner and pro) in all 10 languages, with a language switcher at the top.
