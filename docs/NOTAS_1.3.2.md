# Lienzo UI 1.3.2

- **Simplified Chinese, Japanese and Korean** for the interface, the built-in tutorial and the written tutorials: Lienzo UI now speaks 10 languages. Switch in **Accessibility › Language**.
- It uses the fonts your system already has (Microsoft YaHei, Yu Gothic, Malgun Gothic on Windows), loaded only when you pick one of these languages; if one is missing, Accessibility tells you.
- Written tutorials (beginner and pro) in all 10 languages, with a language switcher at the top.
