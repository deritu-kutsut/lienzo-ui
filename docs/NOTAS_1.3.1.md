# Lienzo UI 1.3.1

## Español
- **5 idiomas nuevos:** portugués, francés, alemán, italiano y ruso, en la interfaz y en el tutorial integrado. Cámbialo en **Accesibilidad › Idioma**.
- **Tutoriales en inglés** en `docs/` y tutoriales al día con la 1.3 (plantillas nuevas, componentes listos y Revisar).
- **Más textos traducidos:** tamaños de página, pantallas del modo prueba, atajos, títulos de sección de Elementos, tipo de elemento y fuente predeterminada.
- Las etiquetas largas de las miniaturas se acortan con «…» y muestran el nombre completo al pasar el ratón.

## English
- **5 new languages:** Portuguese, French, German, Italian and Russian, for the interface and the built-in tutorial. Switch in **Accessibility › Language**.
- **English tutorials** in `docs/`, and all tutorials updated for 1.3 (new templates, ready-made components and Review).
- **More of the interface translated:** page sizes, test-mode screens, shortcuts, Elements section titles, element type and default font.
- Long thumbnail labels are shortened with "…" and show the full name on hover.
