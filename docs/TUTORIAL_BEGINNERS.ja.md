# 初心者向けチュートリアル

🌐 [English](TUTORIAL_BEGINNERS.md) · [Español](TUTORIAL_BEGINNERS.es.md) · [Português](TUTORIAL_BEGINNERS.pt.md) · [Français](TUTORIAL_BEGINNERS.fr.md) · [Deutsch](TUTORIAL_BEGINNERS.de.md) · [Italiano](TUTORIAL_BEGINNERS.it.md) · [Русский](TUTORIAL_BEGINNERS.ru.md) · [简体中文](TUTORIAL_BEGINNERS.zh.md) · [日本語](TUTORIAL_BEGINNERS.ja.md) · [한국어](TUTORIAL_BEGINNERS.ko.md)

Lienzo UI で初めてのインターフェースを作り、Unity へ初めてエクスポートするまでの手順です。プログラミングは不要です。

## 1. インストールして開く

1. GitHub のリリースまたは itch.io から `LienzoUI-windows.zip` をダウンロードします。
2. 解凍して `lienzo-ui.exe` を開きます。
3. 初回起動時は**チュートリアル**（この内容と同じもの）がアプリ内で開きます。最後まで進むか、「スキップしてエディターへ」を押すとエディターが開きます。もう一度見るには、上部バーの **チュートリアル** ボタンまたは **F1** を押します。

アプリを日本語で使うには：**アクセシビリティ** ボタン › **言語** › 日本語。

![アプリ内のチュートリアル](images/tutorial.png)

## 2. 画面構成

| エリア | 内容 |
|---|---|
| 上部バー | ファイル、編集、表示、キャンバス、**テスト**、デザイン名、**アクセシビリティ**、**チェック**、**テーマ**、**チュートリアル**、**保存**、**コード…**、**Unity へエクスポート** |
| 左側バー | **ヒエラルキー**（レイヤー）、**要素**、**テンプレート**、**テキスト**、**画像**、**プラグイン**、**コミュニティ** |
| 中央 | キャンバス：ゲームの画面（デフォルトは 1920 × 1080） |
| 右側 | **インスペクター**：選択中の要素のプロパティ |

![エディター](images/editor.png)

## 3. テンプレートから始める

**テンプレート** から12種類のレイアウト（メインメニュー、ゲーム HUD、ダイアログウィンドウ、設定、インベントリ、ポーズメニュー、ゲームオーバー、ステージ選択、ロード画面、キャラクター会話、ランキング、キャラクター選択）のいずれかを選びます。配置されている要素はすべて変更でき、Ctrl+Z で元に戻せます。白紙から始める場合は「空白」を選びます。

## 4. 編集する

- **要素** からキャンバスへ要素をドラッグします。**既製コンポーネント** にはボタン、HPバー・MPバー、カード、バッジ、インベントリのスロットがあります。
- **テキスト** には見出しスタイルや HUD パーツ（スコア、タイマー、コイン、ダメージ、コンボ、レベルタグ、会話字幕）があります。
- クリックで選択、ドラッグで移動、四隅でサイズ変更、上部のハンドルで回転します。
- テキストをダブルクリックすると文字を入力できます。
- **インスペクター** でカラー、枠線、影、フォント、アンカーを変更できます。

| ショートカット | 操作 |
|---|---|
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+D / Del | 複製 / 削除 |
| Ctrl+G / Ctrl+Shift+G | グループ化 / 解除 |
| 矢印キー (Shift) | 1 px 移動 (10 px) |
| Ctrl+S | 保存 |
| F5 | テスト |
| Ctrl+E | Unity へエクスポート |
| F1 | チュートリアル |

## 5. テストする

**テスト** (F5) を押すと、インターフェースを実際に操作できるようになり、他の画面サイズ（スマホ、4:3、ウルトラワイド）を選んでどのように適応するか確認できます。Esc でテストモードを終了すると、デザインはテスト前の状態に戻ります。

## 6. チェックする

上部バーの **チェック** を押します。読みにくいほど小さい文字、低いコントラスト、タップしにくい小さなボタン、ページからはみ出た要素、重複した名前、見つからない画像を警告します。警告をクリックすると該当する要素が選択され、すぐに修正できます。

## 7. Unity へエクスポートする

1. **Unity へエクスポート** (Ctrl+E) を押します。初回はプロジェクトのフォルダー（`Assets` が入っているフォルダー）を選択します。
2. Unity に戻ると、`Assets/EditorGUI/Prefabs` にデザインが Prefab として作成されています。
3. シーンにドラッグするか、メニューの **Tools › Lienzo UI › Import design into scene…**を使用します。

再エクスポートするたびに、Unity が自動で Prefab を更新します。
