# 初心者向けチュートリアル

🌐 [English](TUTORIAL_BEGINNERS.md) · [Español](TUTORIAL_BEGINNERS.es.md) · [Português](TUTORIAL_BEGINNERS.pt.md) · [Français](TUTORIAL_BEGINNERS.fr.md) · [Deutsch](TUTORIAL_BEGINNERS.de.md) · [Italiano](TUTORIAL_BEGINNERS.it.md) · [Русский](TUTORIAL_BEGINNERS.ru.md) · [简体中文](TUTORIAL_BEGINNERS.zh.md) · [日本語](TUTORIAL_BEGINNERS.ja.md) · [한국어](TUTORIAL_BEGINNERS.ko.md)

Lienzo UI で初めてのインターフェースを作り、Unity へ初めてエクスポートするまでの手順です。プログラミングは不要です。

## 1. インストールして開く

1. GitHub のリリースまたは itch.io から `LienzoUI-windows.zip` をダウンロードします。
2. 解凍して `lienzo-ui.exe` を開きます。
3. 初回起動時は**チュートリアル**（この内容と同じもの）がアプリ内で開きます。最後まで進むか、「スキップしてエディターへ」を押すとエディターが開きます。もう一度見るには、上部バーの **チュートリアル** ボタンまたは **F1** を押します。

アプリを日本語で使うには：**アクセシビリティ** ボタン › **言語** › 日本語。

![アプリ内のチュートリアル](images/tutorial.png)

## 2. 画面構成

| エリア | 内容 |
|---|---|
| 上部バー | ファイル、編集、表示、キャンバス、**テスト**、デザイン名、**アクセシビリティ**、**チェック**、**テーマ**、**チュートリアル**、**保存**、**コード…**、**Unity へエクスポート** |
| 左側バー | **ヒエラルキー**（レイヤー）、**要素**、**テンプレート**、**テキスト**、**画像**、**プラグイン**、**コミュニティ** |
| 中央 | キャンバス：ゲームの画面（デフォルトは 1920 × 1080） |
| 右側 | **インスペクター**：選択中の要素のプロパティ |

![エディター](images/editor.png)

## 3. テンプレートから始める

**テンプレート** から15種類のレイアウト（メインメニュー、ゲーム HUD、ダイアログウィンドウ、設定、インベントリ、ポーズメニュー、ゲームオーバー、ステージ選択、ロード画面、キャラクター会話、ランキング、キャラクター選択）のいずれかを選びます。配置されている要素はすべて変更でき、Ctrl+Z で元に戻せます。白紙から始める場合は「空白」を選びます。そのうち2つはピクセルアート風です：ピクセルRPG HUD とピクセルメインメニュー。

## 4. 編集する

- **要素** からキャンバスへ要素をドラッグします。**既製コンポーネント** にはボタン、HPバー・MPバー、カード、バッジ、インベントリのスロットがあります。
- **テキスト** には見出しスタイルや HUD パーツ（スコア、タイマー、コイン、ダメージ、コンボ、レベルタグ、会話字幕）があります。
- クリックで選択、ドラッグで移動、四隅でサイズ変更、上部のハンドルで回転します。
- テキストをダブルクリックすると文字を入力できます。
- **インスペクター** でカラー、枠線、影、フォント、アンカーを変更できます。

| ショートカット | 操作 |
|---|---|
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+D / Del | 複製 / 削除 |
| Ctrl+G / Ctrl+Shift+G | グループ化 / 解除 |
| 矢印キー (Shift) | 1 px 移動 (10 px) |
| Ctrl+S | 保存 |
| F5 | テスト |
| Ctrl+E | Unity へエクスポート |
| F1 | チュートリアル |

## 5. テストする

**テスト** (F5) を押すと、インターフェースを実際に操作できるようになり、他の画面サイズ（スマホ、4:3、ウルトラワイド）を選んでどのように適応するか確認できます。Esc でテストモードを終了すると、デザインはテスト前の状態に戻ります。

## 6. チェックする

上部バーの **チェック** を押します。読みにくいほど小さい文字、低いコントラスト、タップしにくい小さなボタン、ページからはみ出た要素、重複した名前、見つからない画像を警告します。警告をクリックすると該当する要素が選択され、すぐに修正できます。

## 7. Unity へエクスポートする

1. **Unity へエクスポート** (Ctrl+E) を押します。初回はプロジェクトのフォルダー（`Assets` が入っているフォルダー）を選択します。
2. Unity に戻ると、`Assets/EditorGUI/Prefabs` にデザインが Prefab として作成されています。
3. シーンにドラッグするか、メニューの **Tools › Lienzo UI › Import design into scene…**を使用します。

再エクスポートするたびに、Unity が自動で Prefab を更新します。

## 内蔵画像

左側のバーの「画像」タブには、ファイルを用意しなくてもすぐ使える素材が入っています。

- 上のチップで「マイ画像」「背景」「フレーム」「ボタン」「アイコン」「ピクセルアート」「グラデーション」を絞り込めます。検索ボックスでは名前やタグで探せます。
- 項目をクリックすると追加され、キャンバスへドラッグすることもできます。フレームとボタンは 9-slice の境界つきなので、角がゆがまずに伸び縮みします。背景は一番後ろに置かれます。
- 画像は初めて使うときにライブラリへコピーされ、デザインと一緒に Unity へエクスポートされます。
- ピクセルアートのスプライトを使うときは、キャンバスのインスペクター（何も選択していない状態）で「ピクセルアート」をオンにすると、くっきり表示されます。

## 縦向き画面

スマホは縦に持つことがよくあります。Lienzo UI は最初のレイアウトに手を加えず、縦向き用にもう1つレイアウトを持てます。

- 上のバーの「ランドスケープ」/「肖像」ボタン（横向き/縦向き）でビューを切り替えます。
- 何も選択していない状態でインスペクターの「縦向きレイアウト」を開き、「縦向きレイアウトを作成」を押します。要素は横向きでの位置からスタートします。
- 縦向きビューで動かしたりサイズを変えたりした内容は、縦向きレイアウトだけに反映されます。要素を右クリック ›「横向きに戻す」で1つの変更を取り消せます。
- エクスポートには両方のレイアウトが含まれ、Unity では画面が横より縦に長いとき、プレハブが自動で縦向きに切り替わります。

## Unity からインポート

すでに Unity にインターフェースがありますか？ Lienzo UI に取り込めます。

- ファイル ›「Unity からインポート…」
- uGUI のプレハブ（.prefab）、または以前 Lienzo UI でエクスポートしたデザイン（Assets/EditorGUI/Designs/….json）を選びます。
- 新しい未保存のデザインとして開きます。残すにはプロジェクトとして保存してください。
- 正確に変換できなかった部分があれば、警告の一覧がウィンドウで表示されるので、黙って失われることはありません。
- Unity プロジェクトのフォルダーが見つかれば、デザインの画像は自動的に見つかります。

## 作業を失わないために

- 自動保存：Lienzo UI は約1分ごとに復旧用のコピーを保存します。「アクセシビリティ › 自動保存」でオフにできます。
- アプリが予期せず終了した場合、次回の起動時に「未保存の作業を復元しますか？」と聞かれます。「復元」で取り戻し、「破棄」で捨てられます。復元した内容はまだ保存済みのファイルではないので、Ctrl+S で保存してください。
- これまでどおり Ctrl+S でプロジェクトを保存できます。
- 元に戻す（Ctrl+Z）は最大200ステップまで記憶します（メモリの上限もあります）。古いものが破棄されると、ステータスバーに「履歴を整理しました」と表示されます。

## コミュニティ

左側のバーの「コミュニティ」タブは、プラグイン、画像、フォント、テンプレート、要素、テーマの共有カタログです。

- 閲覧とインストールにアカウントは不要です。検索して「インストール」を押すだけです。
- アップロード、報告、ハートを送るには、GitHub または Google でサインインして公開名を決めます。パスワードはありません。アプリが保存するのはその名前だけです。
- プロフィールを作るとき、ルールに同意します：マルウェア、ヘイト、盗用、表示のない18禁コンテンツは禁止です。全文は docs/TERMS.md と docs/COMMUNITY_GUIDELINES.md にあります。
- 18禁コンテンツは非表示で、サインインして「18禁コンテンツを表示」をオンにしたときだけ表示されます。
- 共有されたものはすべて公開前に審査され、ルールに反するものは報告できます。
