# Lienzo UI 1.2.0

## Español
- **Actualizaciones desde la app**: cuando hay una versión nueva aparece el botón **Actualizar a X.Y.Z** en la cabecera. Descarga, comprueba la huella SHA-256 e instala sin salir de Lienzo UI; funciona igual si la bajaste de GitHub o de itch.io. Se puede desactivar la búsqueda al abrir, omitir una versión o buscar a mano en **Archivo → Buscar actualizaciones…**.
- Servidor MCP más robusto: valida rangos, nombres duplicados o vacíos y diseños corruptos.
- Quien tenga la 1.1.1 debe descargar esta versión a mano una vez; desde aquí se actualiza sola.

## English
- **In-app updates**: when a new version is out, an **Update to X.Y.Z** button appears in the header. It downloads, checks the SHA-256 checksum and installs without leaving Lienzo UI; it works the same whether you got the app from GitHub or itch.io. You can turn off the startup check, skip a version or check manually from **File → Check for updates…**.
- More robust MCP server: validates ranges, empty or duplicate names and corrupt designs.
- If you're on 1.1.1, download this version manually once; from here on it updates itself.
