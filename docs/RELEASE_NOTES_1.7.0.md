# Lienzo UI 1.7.0

Preview and translate in the Community, and templates that fit Portrait pages.

## Added
- **Community: preview before you install.** Fonts show sample text drawn with the font; plugins show their commands, exporters, files and their code (read-only). Nothing is installed and no download is counted.
- **Community: Translate button** on every description. It uses the free MyMemory service only when you press it, shows that the text is an automatic translation, and *Show original* goes back. See the [privacy policy](PRIVACY.md).
- `--page WxH` (with `--template`): page size for screenshots and checks.

## Fixed
- **Templates in Portrait:** a portrait page (for example 1080 x 1920) is now built at 1080 wide instead of 1920 wide and shrunk, which left every template tiny. Settings, Game over, Level select, Loading screen, Character select (2 x 2 cards) and both pixel templates now fit without overlaps. The PC layout is unchanged.
- Character select: the button said "Confirmar" in every language; it now says "Confirm".
