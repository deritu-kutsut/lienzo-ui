# 초보자 튜토리얼

🌐 [English](TUTORIAL_BEGINNERS.md) · [Español](TUTORIAL_NOVATOS.md) · [Português](TUTORIAL_BEGINNERS.pt.md) · [Français](TUTORIAL_BEGINNERS.fr.md) · [Deutsch](TUTORIAL_BEGINNERS.de.md) · [Italiano](TUTORIAL_BEGINNERS.it.md) · [Русский](TUTORIAL_BEGINNERS.ru.md) · [简体中文](TUTORIAL_BEGINNERS.zh.md) · [日本語](TUTORIAL_BEGINNERS.ja.md) · [한국어](TUTORIAL_BEGINNERS.ko.md)

Lienzo UI로 첫 인터페이스를 만들고 Unity로 처음 내보내 봅시다. 프로그래밍은 필요 없습니다.

## 1. 설치 및 열기

1. GitHub 릴리스 또는 itch.io에서 `LienzoUI-windows.zip`을 내려받으세요.
2. 압축을 풀고 `lienzo-ui.exe`를 여세요.
3. 처음 실행하면 **튜토리얼**이 열립니다(이 내용과 같은 내용이 앱 안에 있습니다). 튜토리얼을 마치거나 「건너뛰고 편집기로 이동」을 누르면 편집기가 열립니다. 다시 보려면 상단 막대의 **튜토리얼** 버튼이나 **F1**을 누르세요.

앱을 영어로 사용하려면: **접근성** 버튼 › **언어** › English.

![앱 안의 튜토리얼](imagenes/tutorial.png)

## 2. 화면

| 영역 | 내용 |
|---|---|
| 상단 막대 | 파일, 편집, 보기, 캔버스, **테스트**, 디자인 이름, **접근성**, **검토**, **테마**, **튜토리얼**, **저장**, **코드…**, **Unity로 내보내기** |
| 왼쪽 막대 | **계층 구조**(레이어), **요소**, **템플릿**, **텍스트**, **이미지**, **플러그인**, **커뮤니티** |
| 가운데 | 캔버스: 게임 화면 (기본 1920 × 1080) |
| 오른쪽 | **인스펙터**: 선택한 항목의 속성 |

![편집기](imagenes/editor.png)

## 3. 템플릿에서 시작하기

**템플릿**에서 12가지 레이아웃 중 하나를 고르세요: 메인 메뉴, 게임 HUD, 대화 창, 설정, 인벤토리, 일시정지 메뉴, 게임 오버, 레벨 선택, 로딩 화면, 캐릭터 대화, 순위표, 캐릭터 선택. 모든 것을 바꿀 수 있고, Ctrl+Z로 변경을 실행 취소할 수 있습니다. 처음부터 시작하려면 「빈 화면」을 고르세요.

## 4. 편집

- **요소**에서 캔버스로 요소를 드래그하세요. **완성된 컴포넌트**에는 버튼, 체력 및 마나 바, 카드, 배지, 인벤토리 슬롯이 있습니다.
- **텍스트**에는 제목 스타일과 HUD 요소가 있습니다: 점수, 타이머, 코인, 피해 수치, 콤보, 레벨 표시, 대화 자막.
- 클릭하면 선택, 드래그하면 이동, 모서리를 드래그하면 크기 조절, 위쪽 손잡이로 회전합니다.
- 텍스트를 더블 클릭하면 입력할 수 있습니다.
- **인스펙터**에서 색상, 테두리, 그림자, 글꼴, 앵커를 바꾸세요.

| 단축키 | 동작 |
|---|---|
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+D / Del | 복제 / 삭제 |
| Ctrl+G / Ctrl+Shift+G | 그룹화 / 그룹 해제 |
| 화살표 (Shift) | 1px 이동 (10px) |
| Ctrl+S | 저장 |
| F5 | 테스트 |
| Ctrl+E | Unity로 내보내기 |
| F1 | 튜토리얼 |

## 5. 테스트

**테스트**(F5)를 누르면 인터페이스와 상호작용할 수 있고, 다른 화면(휴대폰, 4:3, 울트라와이드)을 골라 적응 방식을 볼 수 있습니다. Esc로 테스트 모드를 나가면 디자인은 테스트 전 상태로 돌아갑니다.

## 6. 검토

상단 막대의 **검토**를 누르세요. 읽기 어려울 만큼 작은 글자, 낮은 대비, 누르기 어려운 작은 버튼, 페이지 밖의 요소, 중복된 이름, 없는 이미지를 경고합니다. 경고를 클릭하면 해당 요소가 선택되니 고쳐 보세요.

## 7. Unity로 내보내기

1. **Unity로 내보내기**(Ctrl+E)를 누르세요. 처음이라면 `Assets`가 들어 있는 프로젝트 폴더를 고르세요.
2. Unity로 돌아가면 디자인이 `Assets/EditorGUI/Prefabs`에 프리팹으로 나타납니다.
3. 프리팹을 장면으로 드래그하거나 메뉴 **Tools › Lienzo UI › Import design into scene…**를 사용하세요.

내보낼 때마다 Unity가 프리팹을 자동으로 업데이트합니다.
