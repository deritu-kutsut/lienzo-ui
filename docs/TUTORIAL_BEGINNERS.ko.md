# 초보자 튜토리얼

🌐 [English](TUTORIAL_BEGINNERS.md) · [Español](TUTORIAL_BEGINNERS.es.md) · [Português](TUTORIAL_BEGINNERS.pt.md) · [Français](TUTORIAL_BEGINNERS.fr.md) · [Deutsch](TUTORIAL_BEGINNERS.de.md) · [Italiano](TUTORIAL_BEGINNERS.it.md) · [Русский](TUTORIAL_BEGINNERS.ru.md) · [简体中文](TUTORIAL_BEGINNERS.zh.md) · [日本語](TUTORIAL_BEGINNERS.ja.md) · [한국어](TUTORIAL_BEGINNERS.ko.md)

Lienzo UI로 첫 인터페이스를 만들고 Unity로 처음 내보내 봅시다. 프로그래밍은 필요 없습니다.

## 1. 설치 및 열기

1. GitHub 릴리스 또는 itch.io에서 `LienzoUI-windows.zip`을 내려받으세요.
2. 압축을 풀고 `lienzo-ui.exe`를 여세요.
3. 처음 실행하면 **튜토리얼**이 열립니다(이 내용과 같은 내용이 앱 안에 있습니다). 튜토리얼을 마치거나 「건너뛰고 편집기로 이동」을 누르면 편집기가 열립니다. 다시 보려면 상단 막대의 **튜토리얼** 버튼이나 **F1**을 누르세요.

앱을 영어로 사용하려면: **접근성** 버튼 › **언어** › English.

![앱 안의 튜토리얼](images/tutorial.png)

## 2. 화면

| 영역 | 내용 |
|---|---|
| 상단 막대 | 파일, 편집, 보기, 캔버스, **테스트**, 디자인 이름, **접근성**, **검토**, **테마**, **튜토리얼**, **저장**, **코드…**, **Unity로 내보내기** |
| 왼쪽 막대 | **계층 구조**(레이어), **요소**, **템플릿**, **텍스트**, **이미지**, **플러그인**, **커뮤니티** |
| 가운데 | 캔버스: 게임 화면 (기본 1920 × 1080) |
| 오른쪽 | **인스펙터**: 선택한 항목의 속성 |

![편집기](images/editor.png)

## 3. 템플릿에서 시작하기

**템플릿**에서 15가지 레이아웃 중 하나를 고르세요: 메인 메뉴, 게임 HUD, 대화 창, 설정, 인벤토리, 일시정지 메뉴, 게임 오버, 레벨 선택, 로딩 화면, 캐릭터 대화, 순위표, 캐릭터 선택. 모든 것을 바꿀 수 있고, Ctrl+Z로 변경을 실행 취소할 수 있습니다. 처음부터 시작하려면 「빈 화면」을 고르세요.그중 두 가지는 픽셀 아트 스타일입니다: 픽셀 RPG HUD와 픽셀 메인 메뉴.

## 4. 편집

- **요소**에서 캔버스로 요소를 드래그하세요. **완성된 컴포넌트**에는 버튼, 체력 및 마나 바, 카드, 배지, 인벤토리 슬롯이 있습니다.
- **텍스트**에는 제목 스타일과 HUD 요소가 있습니다: 점수, 타이머, 코인, 피해 수치, 콤보, 레벨 표시, 대화 자막.
- 클릭하면 선택, 드래그하면 이동, 모서리를 드래그하면 크기 조절, 위쪽 손잡이로 회전합니다.
- 텍스트를 더블 클릭하면 입력할 수 있습니다.
- **인스펙터**에서 색상, 테두리, 그림자, 글꼴, 앵커를 바꾸세요.

| 단축키 | 동작 |
|---|---|
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+D / Del | 복제 / 삭제 |
| Ctrl+G / Ctrl+Shift+G | 그룹화 / 그룹 해제 |
| 화살표 (Shift) | 1px 이동 (10px) |
| Ctrl+S | 저장 |
| F5 | 테스트 |
| Ctrl+E | Unity로 내보내기 |
| F1 | 튜토리얼 |

## 5. 테스트

**테스트**(F5)를 누르면 인터페이스와 상호작용할 수 있고, 다른 화면(휴대폰, 4:3, 울트라와이드)을 골라 적응 방식을 볼 수 있습니다. Esc로 테스트 모드를 나가면 디자인은 테스트 전 상태로 돌아갑니다.

## 6. 검토

상단 막대의 **검토**를 누르세요. 읽기 어려울 만큼 작은 글자, 낮은 대비, 누르기 어려운 작은 버튼, 페이지 밖의 요소, 중복된 이름, 없는 이미지를 경고합니다. 경고를 클릭하면 해당 요소가 선택되니 고쳐 보세요.

## 7. Unity로 내보내기

1. **Unity로 내보내기**(Ctrl+E)를 누르세요. 처음이라면 `Assets`가 들어 있는 프로젝트 폴더를 고르세요.
2. Unity로 돌아가면 디자인이 `Assets/EditorGUI/Prefabs`에 프리팹으로 나타납니다.
3. 프리팹을 장면으로 드래그하거나 메뉴 **Tools › Lienzo UI › Import design into scene…**를 사용하세요.

내보낼 때마다 Unity가 프리팹을 자동으로 업데이트합니다.

## 기본 제공 이미지

왼쪽 막대의 이미지 탭에는 파일 없이도 바로 쓸 수 있는 소재가 들어 있습니다.

- 위쪽 칩으로 내 이미지, 배경, 프레임, 버튼, 아이콘, 픽셀 아트, 그라디언트를 걸러 볼 수 있습니다. 검색창은 이름이나 태그로 찾습니다.
- 항목을 클릭하면 추가되고, 캔버스로 끌어다 놓아도 됩니다. 프레임과 버튼은 9-slice 테두리가 이미 설정되어 있어서 모서리가 일그러지지 않고 늘어납니다. 배경은 맨 뒤에 놓입니다.
- 이미지는 처음 사용할 때 라이브러리로 복사되고, 디자인과 함께 Unity로 내보내집니다.
- 픽셀 아트 스프라이트를 쓸 때는 캔버스 인스펙터(아무것도 선택하지 않은 상태)에서 「픽셀 아트」를 켜서 선명하게 유지하세요.

## 세로 화면

휴대폰은 세로로 드는 경우가 많습니다. Lienzo UI는 첫 번째 레이아웃을 건드리지 않고 세로용 레이아웃을 따로 둡니다.

- 위쪽 막대의 「풍경」/「초상화」 버튼(가로/세로)으로 보기를 전환합니다.
- 아무것도 선택하지 않은 상태에서 인스펙터의 「세로 레이아웃」을 열고 「세로 레이아웃 만들기」를 누르세요. 요소는 가로 화면에서의 위치 그대로 시작합니다.
- 세로 보기에서 옮기거나 크기를 바꾼 내용은 세로 레이아웃에만 반영됩니다. 요소를 마우스 오른쪽 버튼으로 클릭 ›「가로로 되돌리기」로 변경 하나를 취소할 수 있습니다.
- 내보내기에는 두 레이아웃이 모두 들어 있어서, Unity에서는 화면이 가로보다 세로가 길 때 프리팹이 알아서 세로 레이아웃으로 바뀝니다.

모든 템플릿에는 세로 레이아웃이 처음부터 들어 있습니다. 템플릿을 적용한 뒤 「초상화」 버튼(세로)을 누르면 휴대폰에 맞춘 레이아웃(1080 × 1920)을 볼 수 있습니다.

## Unity에서 가져오기

이미 Unity에 인터페이스가 있나요? Lienzo UI로 가져올 수 있습니다.

- 파일 ›「Unity에서 가져오기…」
- uGUI 프리팹(.prefab) 또는 예전에 Lienzo UI에서 내보낸 디자인(Assets/EditorGUI/Designs/….json)을 고르세요.
- 저장되지 않은 새 디자인으로 열립니다. 보관하려면 프로젝트로 저장하세요.
- 정확하게 변환하지 못한 부분이 있으면 경고 목록이 창으로 표시되므로 조용히 사라지는 것은 없습니다.
- Unity 프로젝트 폴더를 찾으면 디자인의 이미지도 자동으로 찾습니다.

## 작업을 잃지 않도록

- 자동 저장: Lienzo UI는 약 1분마다 복구용 사본을 저장합니다. 「접근성 › 자동 저장」에서 끌 수 있습니다.
- 앱이 예기치 않게 종료되면 다음 실행 때 「저장되지 않은 작업을 복구할까요?」라고 묻습니다. 「복원」을 누르면 되살리고, 「삭제」를 누르면 버립니다. 복구한 내용은 아직 저장된 파일이 아니므로 Ctrl+S로 저장하세요.
- Ctrl+S는 이전처럼 프로젝트를 저장합니다.
- 실행 취소(Ctrl+Z)는 최대 200단계까지 기억합니다(메모리 한도도 있습니다). 가장 오래된 단계가 삭제되면 상태 표시줄에 「기록 정리됨」이라고 표시됩니다.

## 커뮤니티

왼쪽 막대의 커뮤니티 탭은 플러그인, 이미지, 글꼴, 템플릿, 요소, 테마를 모아 둔 공유 카탈로그입니다.

- 둘러보기와 설치에는 계정이 필요 없습니다. 검색한 뒤 「설치」를 누르면 됩니다.
- 업로드, 신고, 하트 주기를 하려면 GitHub 또는 Google로 로그인하고 공개 이름을 정합니다. 비밀번호는 없으며, 앱은 그 이름만 저장합니다.
- 프로필을 만들 때 규칙에 동의합니다. 악성 코드, 혐오, 표절, 표시하지 않은 +18 콘텐츠는 금지입니다. 전문은 docs/TERMS.md와 docs/COMMUNITY_GUIDELINES.md에 있습니다.
- +18 콘텐츠는 숨겨져 있으며, 로그인하고 「+18 콘텐츠 표시」를 켜야 보입니다.
- 공유된 모든 것은 공개 전에 검토되며, 규칙에 어긋나는 것은 신고할 수 있습니다.

글꼴과 플러그인에서는 설치하기 전에 「미리보기」를 눌러 예시 텍스트를 보거나 플러그인이 하는 일과 코드를 읽을 수 있습니다. 아무것도 설치되지 않습니다. 「번역」을 누르면 모든 설명을 내 언어로 읽을 수 있습니다. 누를 때만 무료 온라인 서비스를 사용하며, 「원문 보기」로 되돌릴 수 있습니다.
