# Lienzo UI 1.4.0

English-first release. Code, command line, MCP tools, plugin manifests, sample designs, the Unity package and the documentation now use English names; Spanish remains a language of the interface, the tutorials and the guides.

- **Nothing breaks:** the old Spanish command-line flags, MCP tool names, plugin manifest keys, test-mode functions and the `disenos` folder are still accepted. Saved designs, settings and themes load as before.
- **Interface:** all 10 languages re-translated against the new English source.
- **Community:** English server names and wire format; versions 1.0 - 1.3.3 keep working.
- **Docs:** pages and screenshots renamed to English names; the old links still work.
